## overview

a lightweight, privacy-focused tool for understanding personal spending habits. monthly
credit card statements go in, transactions get categorized by hand, and interactive
dashboards show where the money actually goes.

the rule is simple: all data stays local. this is a personal finance tool, not a
data-collection service, so there is no cloud component to trust: the app, the database,
and the statements live on one machine.

## features

- upload monthly credit card statements
- automatic parsing of transaction data
- manual transaction categorization
- spending summaries by category
- historical spending trends
- interactive dashboard visualizations

## stack

frontend: Next.js (App Router), React, TypeScript. backend: Next.js API routes with a
Prisma ORM over PostgreSQL. authentication via NextAuth. a local Docker database keeps
everything on one machine.
