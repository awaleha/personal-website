## overview

a Next.js web app built on top of Riot's developer API for exploring League of Legends
match data. the companion repository [Riot-API-Testing](https://github.com/awaleha/Riot-API-Testing)
holds the backend scripts used for data manipulation.

this one was an exploration project: learn a public API, pull interesting data out of it,
and get it onto a screen. it retired once the interesting questions had been answered,
which is a fine end for a sandbox.
