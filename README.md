# awalehassan.com

Personal portfolio site — Next.js static export, deployed on Cloudflare Pages.

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The static site is written to `out/`.

## Content

- Site config, routes, theme: `src/resources/once-ui.config.ts`
- Person, socials, About, skills: `src/resources/content.tsx`
- Case studies: `src/app/work/projects/*.mdx`
